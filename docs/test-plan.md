# Plan de pruebas - SauceDemo

## 1. Alcance de las Pruebas (Test Scope)

### Dentro del Alcance (In-Scope)
- **Módulo de Login:** Validación de credenciales válidas e inválidas.
- **Gestión de Carrito:** Adición, eliminación y actualización de ítems.
- **Checkout:** Compleción del formulario del cliente y pantalla final de orden.
- **Navegadores:** Google Chrome (Desktop).

### Fuera del Alcance (Out-of-Scope)
- Pruebas de rendimiento y estrés.
- Integración con pasarelas de pago reales.
- Pruebas de seguridad avanzadas.
